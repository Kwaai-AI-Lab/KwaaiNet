# distrib/

Everything that turns a KwaaiNet build into something someone else can install.

| Directory | Mechanism |
|-----------|-----------|
| [`nix/`](nix/README.md) | Reproducible builds, cross-compilation, OCI containers, and the dev shell — driven by the root `flake.nix` and `Makefile`. |

Release archives, shell/PowerShell installers and the Homebrew tap are not here:
they are generated by cargo-dist from `[workspace.metadata.dist]` in
`core/Cargo.toml` and published by `.github/workflows/release.yml`.

## Notes

`nix/` moved here from the repository root with no functional change. Two things
about that are worth knowing before editing it:

- **Nix flakes only see git-tracked files.** A new file under `distrib/` is
  invisible to `nix build` until it is `git add`ed, and the failure is a
  confusing "file not found" rather than anything mentioning git.
- **`crane.nix` and `proto.nix` reach the repository root by relative path**
  (`./../..` and `../../core/...`). They are two directories deep now, not one.
  A path that silently resolves to `distrib/` instead of the root produces an
  evaluation error a long way from the cause.
