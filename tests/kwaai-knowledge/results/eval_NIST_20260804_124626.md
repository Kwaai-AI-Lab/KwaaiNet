### q20 — Edge case: MITRE ATLAS is explicitly modeled after another well-known MITRE framework — name it, and explain what conceptual structure (tactics/techniques) it borrows from that framework.

The MITRE ATLAS Adversarial Threat Landscape is explicitly modeled after the MITRE ATT&CK (Adversarial Tactics, Techniques & Common Knowledge) framework [1].

The ATT&CK framework provides a comprehensive and structured approach to describing the tactics, techniques, and procedures (TTPs) used by adversaries to compromise systems and networks. It categorizes TTPs into two primary categories:

1. **Tactics**: These are the high-level goals or objectives of an attack, such as:
	* Initial Access
	* Execution
	* Persistence
	* Privilege Escalation
	* Defense Evasion
	* Credential Access
	* Discovery
	* Lateral Movement
	* Collection
	* Command and Control
	* Resource Development
2. **Techniques**: These are the specific methods or actions used to achieve a tactic, such as:
	* Spearphishing
	* Ransomware
	* SQL Injection
	* Malware (e.g., malware variants, execution methods)
	* User Execution (e.g., executing malicious files, macros)

The MITRE ATLAS Adversarial Threat Landscape borrows from this conceptual structure by applying it to the context of artificial intelligence and machine learning systems. It categorizes TTPs used by adversaries against AI/ML systems into similar tactics and techniques, such as:

* **Tactics**:
	+ Initial Access (e.g., accessing an AI model's training data)
	+ Execution (e.g., executing a malicious AI inference request)
	+ Persistence (e.g., maintaining access to an AI system after initial compromise)
	+ Defense Evasion (e.g., using AI-generated content to evade detection)
* **Techniques**:
	+ Adversarial Machine Learning (AML) attacks, such as injecting malware or manipulating training data
	+ Model Poisoning (e.g., corrupting the model's weights or biases)
	+ Data Tampering (e.g., modifying or falsifying input data)

By applying this conceptual structure to AI/ML systems, MITRE ATLAS provides a structured approach for analyzing and understanding the tactics, techniques, and procedures used by adversaries against these systems.
