### q15 — What is the purpose of NIST SP 800-218A, and how does it relate to the base Secure Software Development Framework (SSDF)?

The SSDF Community Profile for AI Model Development is intended to be used in conjunction with the base SSDF version 1.1 and NIST Special Publication (SP) 800-218, Secure Software Development Framework (SSDF) Version 1.1: Recommendations for Mitigating the Risk of Software Vulnerabilities [6].
