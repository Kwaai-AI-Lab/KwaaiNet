2. **Flow control**: QUIC includes flow control mechanisms to limit stream creation and bound the amount of data that can be sent on each stream (source [16] and [20]).
3. **Multiplexing**: QUIC allows multiple streams to operate concurrently, allowing multiple applications or services to share a single connection (source [4], [17], and [20]).
4. **Security features**: QUIC provides confidentiality protection and encryption for the entirety of each packet, as well as authentication (source [16] and [17]).
5. **Error handling and recovery**: QUIC includes mechanisms for error detection and correction, such as retransmission and acknowledgement of lost packets (source [13], [14], and [15]).
6. **Packet coalescing**: QUIC allows multiple packets to be coalesced into a single UDP datagram, reducing the number of UDP datagrams needed and improving efficiency (source [14] and [15]).
7. **Connection migration**: QUIC provides mechanisms for migrating connections between different network paths or endpoints (source [4]).

These features, among others, make QUIC suitable for modern web transport by providing a more efficient, secure, and reliable way to transfer data over the internet compared to UDP alone.
